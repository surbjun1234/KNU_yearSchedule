# SCH: 경북대학교 학사 일정 알림 크롤링 시스템

## 프로젝트 개요

`SCH` 프로젝트는 경북대학교의 학사 일정을 주기적으로 크롤링하여 변경되거나 새로운 일정이 있을 경우 사용자에게 알림을 제공하는 자동화된 시스템입니다. 이 시스템은 학생들이나 교직원들이 중요한 학사 일정을 놓치지 않도록 돕는 것을 목표로 합니다.

## 주요 기능

*   **경북대학교 학사 일정 크롤링**: 경북대학교 웹사이트에서 학사 일정을 주기적으로 수집합니다.
*   **새로운 일정 감지**: 이전에 수집된 일정과 비교하여 변경되거나 새로운 일정이 게시되었는지 확인합니다.
*   **웹훅 알림**: 새로운 일정이 감지되면 설정된 웹훅(예: Discord)을 통해 관련 정보를 전송합니다.
*   **날짜 기반 필터링**: 특정 기간 내의 일정을 효율적으로 필터링하고 알림을 보냅니다.

## 사용 기술

*   **Python**: 핵심 크롤링 로직 구현
*   **`requests`**: 웹 페이지 요청
*   **`BeautifulSoup4`**: HTML 파싱 및 데이터 추출
*   **`os`, `re`, `datetime`, `difflib`, `urllib.parse`**: 파일 시스템, 정규 표현식, 날짜/시간 처리, 문자열 비교, URL 처리 등
*   **GitHub Actions**: 스케줄링된 작업 실행 (예상)

## 설치 및 실행 방법

1.  **레포지토리 클론**: 
    ```bash
    git clone https://github.com/surbjun1234/SCH.git
    cd SCH
    ```

2.  **의존성 설치**: 
    ```bash
    pip install -r requirements.txt
    ```

3.  **환경 변수 설정**: 
    `WEBHOOK_DATE` 환경 변수에 Discord 웹훅 URL을 설정해야 합니다. 이는 GitHub Secrets를 통해 관리하는 것이 권장됩니다.

4.  **실행**: 
    ```bash
    python main.py
    ```
    이 스크립트는 주로 GitHub Actions와 같은 CI/CD 환경에서 주기적으로 실행되도록 설계되었습니다.
